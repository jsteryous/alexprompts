# Rebrew

The website for **The Rebrew Intelligencer** at [www.rebrew.org](https://www.rebrew.org): the real
news three mornings a week, printed as a 1945 American daily. Next.js on Vercel, data in Supabase,
written and printed by Claude routines. See `CLAUDE.md` for how it fits together and
`scripts/intelligencer/` for the press, the Publisher and the strategy.
